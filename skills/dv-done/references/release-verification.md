# 发布验收（只读默认）

独立于任务本地完成，不增加dv-deploy，不默认从本地发布。

1. 确认环境URL/服务/制品与期望SHA或不可变版本，读取CI匹配结果。
2. 区分构建制品、部署任务、运行镜像/版本。版本接口/镜像digest等实际证据优先，不以部署日志独自证明目标已更新。
3. 授权环境健康检查、关键API/页面、相关日志/告警；健康200不代表权限/数据业务正确。
4. 涉及写入的烟测使用隔离测试账号/fixture，明确副作用与清理；生产写入需另行授权。
5. 报告代码已推送/构建/部署执行/版本确认/关键功能逐项状态及证据，缺权限记未验证。
6. 失败提供诊断、风险和回滚入口建议，不执行本地部署/回滚/CI审批。紧急发布也必须走明确授权的既有路径与制品。

本地开发服务/临时预览不等于生产部署；无CI的离线边缘环境可规划人工既有脚本，但本skill仅验证。
