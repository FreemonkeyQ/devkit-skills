# 真实UI与浏览器验收

## 适用 / 不适用
Web真实流程、布局状态、性能/内存；纯后端测试用test。桌面端参考 references/desktop-validation.md，浏览器只能覆盖渲染部分。

## 流程
1. 读取目标环境、已有服务与仓库命令；优先复用，不擅自关闭现有进程。必要时重启受改动服务，确认版本已加载。没有入口报告缺口。
2. 先快照/DOM识别元素，再交互；检查相关console/network/接口结果。只读验收默认，创建测试数据使用隔离账号/fixture并说明清理。
3. 逐项对照验收标准记录前提、操作、预期、实际。需要时选择长文本/空态/缺图/大列表/断网，不给每页强行套六项。
4. 视觉检查用可读截图与DOM几何交叉；模型无法读图则明确“未直接视觉核对”，不能把探针等同完整审美验收。
5. 性能有基线、环境、采样次数和测量方式；内存上涨需区分缓存和泄漏。高负载/生产修改需额外授权。
6. 报告观察/推断/未验证，测试脚本与报告按项目规则保存。发现问题只报告，修复交build，重新验收后done。

## 自检
不用单元测试代替真实UI操作；不用截图代替IPC/系统权限/安装测试；不伪称已启动或看过。验收失败不得标记相关目标通过。
