# 桌面端不能只验浏览器

## 分层
渲染UI：DOM/截图/键盘/窗口尺寸。
主进程/preload/IPC：来源、参数、权限、并发、错误返回和监听释放。
OS集成：文件/协议/托盘/设备/多实例/休眠唤醒/系统代理。
交付：安装/卸载/升级/签名/自动更新/兼容版本与失败恢复。

Electron可按已有Playwright Electron能力等入口验证；原生框架用其已有runner/测试工具。
没有桌面自动化能力时报告手工验收与目标OS缺口，不能把Web E2E绿当Windows验收。
Mac验证不替代Windows runner。测试账号、设备、目录隔离，禁止真实客户数据和未经授权升级。
记录OS/架构/制品版本、运行方式、复现步骤、观察与未验证项。
