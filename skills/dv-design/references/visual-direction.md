# 视觉方向与反套路判断

用于 `aesthetic` 模式。目的是让界面有明确方向，而不是把默认组件换个颜色。

## 先定概念
- 写一句话：这个界面解决什么问题、给谁用、要让人记住的一点是什么。
- 调性只选一个主方向：极简、编辑杂志感、工业/工具感、奢华精致、玩趣、复古未来、有机自然等。方向可以混，但必须有主次。
- 差异化要能落到一个具体元素：字体、构图、图形语言、材质、动效节奏或内容呈现方式。说不出来的“高级感”不算方向。
- 概念优先于样式。样式服务概念，概念不服务样式。

## 默认AI套路红线
以下不是绝对禁止，而是没有理由就不要用：
- 默认字体直接上 Inter / Roboto / Arial / 系统字体，且没有排版处理。
- 白底紫渐变、蓝紫光晕、悬浮玻璃卡片作为默认“科技感”。
- 居中大标题＋一行副标题＋三张等宽图标卡片的首屏。
- 一排没有信息量的图标、装饰线、胶囊标签。
- 所有卡片同一圆角、同一阴影、同一间距，页面没有主次。
- 用 Lorem、灰条和假数字冒充内容。
- 每个项目都收敛到同一套“安全”选择。

## 排版
- 展示字体与正文字体分工；字号、字重、行高形成明确层级，而不是只靠加粗。
- 先定正文可读性，再处理展示字号；长文本、数字表格和中文混排单独检查。
- 同一产品保持一套字体决策；换页面不换语言。

## 色彩
- 定主色、强调色、中性色和语义色；用 token 表达，不散落硬编码。
- 允许主色占比明显、强调色少量；均匀分布的“安全配色”通常没有记忆点。
- 深色/浅色主题都要验证对比度与状态可辨；正文对比度按 `design-engineering.md` 的无障碍要求。

## 空间与构图
- 非对称、重叠、网格打破、留白或高密度都可以，但必须服务信息层级。
- 页面要有节奏：密集区与呼吸区交替，而不是每块等权重。
- 响应式不是把桌面布局压窄；关键内容、操作和导航在各宽度下都要成立。

## 动效
- 先问目的：反馈、空间连续、注意力引导还是状态表达；没有目的就不加。
- 优先一次有编排的入场和少量高价值微交互，少而准优于到处都是。
- 可打断、可取消、支持 reduced-motion；高频操作不让用户等动画。

## 质感
- 背景、纹理、层次、光影可以增强主题，但不能替代信息设计。
- 装饰元素要可解释：为什么这里有这个图形、材质或分割。
- 性能敏感页面先保守，特效不能拖慢首屏与交互。

## 交付要求
- 给 1-2 个方向时写清取舍：各自适合什么内容、代价是什么。
- 方向确认后固化为 tokens 与组件约束，后续页面复用，不逐页重新发明。
- 高设计感与可用性冲突时，优先可用性，并明确记录舍弃了什么。
