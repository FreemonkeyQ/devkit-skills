# 性能、安全和测试有效性

## 性能
先约定问题、基线、目标、数据量和环境；记录采样、冷/热缓存、并发、p50/p95/p99与错误率。
微基准/JMH/Go benchmark不能代替端到端吞吐；k6等负载工具按项目已有设施使用。
高负载仅隔离环境/授权配额，明确停止阈值，不对生产“试试看”。

## 安全
身份认证和资源授权分开；检查越权、租户隔离、输入校验、路径遍历、命令/SQL注入、日志秘密。
生产只读健康检查不授权扫描/写入；攻击性测试限定拥有授权的隔离目标。
UI隐藏不代表接口禁止；重复提交/签名过期/回放等按业务契约设计。

## 有效性
覆盖率是到达代码，不证明断言强。突变测试需分析存活、无覆盖、超时和等价体，不追求单一数字。
静态规范/复杂度只能提示风险；缺工具时保留基于源码的发现与限制，不编数字。
